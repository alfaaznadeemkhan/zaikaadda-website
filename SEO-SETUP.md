# ZaikaAdda SEO launch checklist

The website includes page title/description, local search terms, Open Graph and Twitter metadata, a FoodEstablishment JSON-LD block, a web manifest, `robots.txt`, and `sitemap.xml`.

## Required before publishing

1. Choose and connect ZaikaAdda's real public domain.
2. Replace `YOUR-ZAIKAADDA-DOMAIN` in `public/robots.txt` and `public/sitemap.xml` with that exact domain (without a trailing slash in the robots sitemap URL).
3. Add the canonical URL and absolute Open Graph/schema image URLs using the real domain.
4. Publish the production build over HTTPS.
5. Verify the domain in Google Search Console and submit `/sitemap.xml`.
6. Create/verify the Google Business Profile only with accurate business details and the correct service area; do not publish a private home address if it should remain private.
7. Add real menu prices, opening/ordering hours and delivery coverage once confirmed. Do not add invented ratings or reviews.
8. Check the live site on mobile, run Google's Rich Results Test and PageSpeed Insights, and confirm the WhatsApp link opens the correct business chat.

SEO cannot guarantee a #1 Google position. Rankings depend on the actual domain, competition, business profile, reviews, useful content, local relevance, links and time. This package provides technical foundations; the domain-specific steps above remain necessary because the ZaikaAdda website domain was not supplied.
